# ⚡ ThunderBolts Color Clash ⚡

An original UNO-style real-time multiplayer color card game.

## Features
- Private room codes
- 2–10 online human players
- Server-authoritative Socket.IO gameplay
- Accurate 108-card classic-style deck
- Skip, Reverse, +2, Wild and +4
- Wild +4 active-color validation
- UNO and Catch UNO
- Draw pile recycling
- Responsive mobile/desktop interface

## Install
```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Test on a phone on the same Wi-Fi
1. Connect phone and computer to the same Wi-Fi.
2. Find your computer IPv4 address using `ipconfig` on Windows.
3. Open:
```text
http://YOUR-IP:3000
```
Example: `http://192.168.1.5:3000`

The server listens on `0.0.0.0`.

## Notes
This version provides the complete online multiplayer foundation. Computer bots and advanced sound/animation systems can be added as the next development phase.
